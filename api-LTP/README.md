## 🛠️ Instalação e Execução

### 1. Pré-requisitos
python 3.10+

### 2. Instalar dependências
Na raiz da pasta `api-LTP`, instale os pacotes necessários:
```bash
pip install -r requirements.txt
```

### 3. Configurar Variáveis de Ambiente
so usar o .env, POREM, se eles detectam um repo publico com isso, a api cai na hora, entao ta vazio por enquanto, mas na apresentação darei acesso ao .env ao senhor luiz

### 4. Executar o Servidor
Para iniciar a API localmente:
```bash
python run.py
```
O servidor iniciará no endereço `http://127.0.0.1:5001`.
