## Como Usar

### Passo 1 — Identificar a dúvida
Entenda o que o aluno quer saber (ex: "Posso participar sendo do 1º ano?", "Qual o tamanho do banner?").

### Passo 2 — Consultar as Regras
Chame `load_skill(skill_nome='regras-da-bragantec')`. O retorno incluirá o conteúdo do arquivo de regras vigente (ex: `regras_bragantec_2025.md`).

### Passo 3 — Validar com o projeto (se necessário)
Se a dúvida for sobre a adequação do projeto do aluno, chame `obter_projetos_usuario()` para ver se o projeto dele cumpre os requisitos citados no edital.

### Passo 4 — Responder de forma Fiel
Responda de forma sintética, citando o ano do edital consultado. Se o aluno estiver descumprindo algo, avise-o proativamente.

## Regras

- ✅ Sempre mencione o ano do edital (ex: "Segundo o edital de 2025...").
- ✅ Seja direto: se algo é obrigatório, use termos como "É obrigatório" ou "Exige-se".
- ✅ Se o aluno perguntar algo que não está no edital, diga que não encontrou a informação específica e sugira contatar a organização.
- ❌ Nunca suponha exceções ("Acho que pode"). Se o edital não prevê, a resposta é baseada apenas no texto.
- ❌ Não confunda Critérios de Avaliação (nota) com Regras de Participação (requisitos).
